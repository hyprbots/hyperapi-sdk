# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting form for this repository:

https://github.com/hyprbots/hyperapi-sdk/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested
mitigation. We will acknowledge the report and coordinate remediation and
disclosure through the private advisory.

Never include real HyperAPI credentials or customer documents in a report.
